## Summary
- probe: Identifies node, confirms protocol mode
- snapshot create: Captures node state to .cdsnap file
- define: Adds user-defined word (modification)
- snapshot diff: Shows differences between snapshot and live node
- snapshot restore: Reloads firmware, applies meta, validates, persists
- probe (verify): Confirms node is operational after restore
